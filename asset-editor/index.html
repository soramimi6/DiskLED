DiskLED Asset Editor

Pick the folder of one asset (skin) you want to check or edit — the folder that directly contains its layout.cfg and images, such as this repository's assets/original/, or a folder of your own anywhere on disk (My Documents, a USB drive, ...). This tool never scans a parent assets/ folder for you; point it at the one asset you're working on. Works even opened directly from disk (file://) — no local web server needed.
