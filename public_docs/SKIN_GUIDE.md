# スキンの自作ガイド

[English](EN/SKIN_GUIDE.md)

DiskLED の見た目（表示モード＝「スキン」）を自作・改造するためのガイドです。編集には同梱のブラウザツール **Asset Editor** を使います。

## 1. スキンとは

- `assets/<id>/` フォルダ 1 つが、表示モード（例: Original、Crystal）1 つに対応します
- フォルダの中身は `layout.cfg`（設定ファイル）と画像ファイルです
- 起動時に `assets/` 直下で `layout.cfg` があるフォルダが自動的に表示モードとして認識されます（プログラムの再ビルドは不要）
- **コンパクト表示とフル表示は完全に独立しています**。設定は一切継承されません（詳しくは後述）

## 2. Asset Editor を開く

1. `asset-editor/index.html` をダブルクリックします（ブラウザが起動します。ネット接続がある方が見た目は良くなりますが、無くても動作します）
2. 「**Load asset folder…**」ボタンで、編集したいスキンのフォルダ（`layout.cfg` を直接含むフォルダ）を選びます。もしくは、そのフォルダをページへ**ドラッグ&ドロップ**しても読み込めます
3. 親フォルダ（`assets/` 自体など）を選んでも読み込まれません。**スキン 1 つ分のフォルダそのもの**を選んでください
4. 新しいスキンを一から作る場合は、空のフォルダを 1 つ用意し、最低限の `layout.cfg`（3節のひな形）を置いてから読み込んでください

Asset Editor はリポジトリの中でなくても、パソコン上のどこのフォルダ（マイドキュメント、USB メモリなど）でも同じように開けます。

## 3. 最低限の `layout.cfg`

```ini
[General]
Id=myskin
Caption=My Skin

[GeneralCompact]
Width=200
Height=32
Transparent=1
MaskColor=#FF00FF
Bg=MyBase.png
```

`Width`・`Height`・`Bg` が揃って初めて有効なスキンになります。`Bg` に指定した画像ファイルは同じフォルダに置きます。

## 4. 画面の見方

| 場所 | 内容 |
|---|---|
| ヘッダー | フォルダ読み込み、表示言語（EN/JA）切替 |
| プレビュー（上部） | 実際の見た目。Compact/Full 切替、表示倍率（x1/x2/x5） |
| セクション（左） | このスキンが持てる全パーツの一覧。既に使われているものはそのまま表示、まだ使っていないものは薄字＋チェックボックスで表示 |
| フィールド編集（中央） | 選択中のセクションの内容を GUI で編集。各項目にマウスを乗せると説明が出ます |
| layout.cfg（右） | 生テキストのエディタ（構文の色分け付き）。GUI 側の編集と常に同期します。**Copy** で全文コピー、**Save** で保存 |
| Test values & diagnostics（下部） | CPU・メモリ等の値を手動で指定してプレビューの動きを確認、layout.cfg の整合性セルフチェック |

GUI で値を変えるとテキスト側の該当行だけが書き換わり、テキストを直接編集すると少し間を置いて GUI 側とプレビューに反映されます。どちらから編集しても構いません。

## 5. 基本ワークフロー

1. スキン用の画像（背景・メーター画像など）を用意し、フォルダに入れる
2. Asset Editor でそのフォルダを読み込む
3. セクション一覧の **General** で `Id`・`Caption` を設定
4. **Compact > Mode**（`GeneralCompact`）で `Width`・`Height`・`Transparent`・`MaskColor`・`Bg` を設定。`Bg` を指定した後に「**Auto-fit to background image**」を押すと、背景画像の実サイズを `Width`/`Height` に自動反映できます
5. 使いたいパーツ（`Cpu` など）にチェックを入れて有効化し、`File`（画像）・`X`/`Y`（位置）・`Frames`（コマ数）などを設定
6. 下部の Test values でメーターの値や LED の点灯を切り替え、プレビューで見た目を確認
7. フル表示も作る場合は、**Full > Mode**（`GeneralFull`）にもチェックを入れて同様に設定（`Width`/`Height`/`Bg` が揃うとフル表示が有効になります）
8. **Save** で `layout.cfg` を保存します。対応ブラウザでは保存先を直接選べます。それ以外のブラウザ（`file://` で開いている場合はほとんどこちらになります）では、ダウンロードされたファイルを元のフォルダへ手動で移動してください
9. 完成したフォルダを DiskLED の `assets/` フォルダの下に置き、右クリックメニューの表示モード一覧から選んで確認します

## 6. コンパクトとフルは独立

**コンパクトとフルの間に継承は一切ありません。** タスクトレイ以外のすべての設定は、コンパクト用・フル用それぞれ専用のセクションに分けて書きます。

| セクション | 内容 | 有無 |
|---|---|---|
| `General` | ID・表示名などモードに依存しない情報 | 常に 1 つ |
| `GeneralCompact`（Compact > Mode） | コンパクトのウィンドウ定義（サイズ・背景・透過） | 必須 |
| `GeneralFull`（Full > Mode） | フルのウィンドウ定義。**これが無ければコンパクトのみのモード**になります | 任意 |
| `GraphFull`（Full > Graph） | フル時のみの推移グラフ | 任意 |
| 各パーツ（`CpuCompact`/`CpuFull` など） | 画像・座標・追従設定・数値表示 | パーツごとに Compact/Full 独立 |

- 片方のセクションだけあれば、そのパーツはそのモードにだけ存在します（例: `DiskIoMeterCompact` だけ書けばフルには出ません）
- 両方の表示に同じパーツを出したい場合は、**両方のセクションに同じ内容を書く**必要があります（Asset Editor 上ではそれぞれ別セクションとして個別にチェック・編集します）

## 7. 透過（カラーキー）

| 対象 | 設定場所 | 内容 |
|---|---|---|
| ウィンドウ全体の外形 | `GeneralCompact`/`GeneralFull` の `Transparent`/`MaskColor` | 指定色のピクセルをウィンドウごと透過させ、背景を透けさせます。`Transparent=0` なら矩形の窓になります |
| 各パーツ（メーター・LED・Ping・数値readout） | 各パーツの `Transparent`/`MaskColor` | パーツの画像だけを個別に透過させます。ウィンドウ全体の透過とは独立しています |

Asset Editor のプレビューは、ウィンドウ全体の透過部分をチェッカーボード柄で表示します。

## 8. パーツの種類

パーツは `<パーツ名>Compact` / `<パーツ名>Full`（例: `CpuCompact`/`CpuFull`）という対の名前を持ちます。セクション一覧では「Meters」「LEDs & Ping」にグループ分けされています。

**メーター系**（`File`/`X`/`Y`/`Frames`/`Transparent`/`MaskColor` に加えて `Kind`/`Strength` の指定が必須）:
`Cpu` `Mem` `Swap` `DiskReadMeter` `DiskWriteMeter` `DiskIoMeter` `NetInMeter` `NetOutMeter` `NetIoMeter` `Audio` `AudioL` `AudioR`

**LED・Ping系**（`File`/`X`/`Y`/`Frames`/`Transparent`/`MaskColor` のみ）:
`Ping` `DiskRead` `DiskWrite` `DiskRW` `NetIn` `NetOut` `NetActivity` `NetTotal`

- `DiskRW` はディスクの読み取り・書き込みのどちらかで点灯します
- `NetTotal` はネットの送受信のどちらかで点灯します（`NetActivity` と同じ条件です）
- `DiskIoMeter`/`NetIoMeter` は読み取り・書き込み（または送受信）の大きい方を示す合成メーターです
- `Ping` は 4 コマ必要です（タイムアウト → 低速 → 普通 → 良好の順）
- 画像は縦方向のストリップ（上から低い値→高い値の順）を想定しています

## 9. メーターの追従設定（Ballistic）

メーター系パーツは、値の変化にどう追従するかを `Kind`（種類）と `Strength`（強さ、0〜100）で指定します（必須項目です）。

| 種類 | 用途の例 | 立ち上がり | 立ち下がり |
|---|---|---|---|
| `vu` | コマ数の多い針メーター | 指数的・やや速い | フルスケール約 0.8 秒 |
| `bar` | 粗い LED バー | 指数的・中程度 | フルスケール約 0.5 秒 |
| `peak` | スパイク（瞬間最大値）表示向け | 指数的・最速 | フルスケール約 1.3 秒 |

なお Asset Editor 自体のプレビューは値をそのままコマへ反映するだけで、この追従アニメーション自体は再現しません（実機での見え方の目安として `Kind`/`Strength` を設定してください）。

## 10. 数値readout（％表示）

`Cpu`/`Mem`/`Swap` のパーツにだけ、使用率を数字で重ねて表示する機能があります。同じセクション内で `ValSW=1` にして有効化します。

- **bitmap**（既定）: パーツごとに専用のフォント画像（横 11 コマ: 0〜9 と空白）を指定します。モード共通のフォントという概念はありません
- **system**: OS のフォントで描画します（フォント名・サイズ・色・太字を指定）

## 11. 推移グラフ（フルのみ）

`GraphFull`（Full > Graph）で、CPU・メモリ・ディスク・ネットの推移をフル表示にだけ描画できます。レーンごとに位置とサイズを `X,Y,W,H` の形式で、色を別途指定します。線（`line`）または棒（`bar`）から選べます。Asset Editor のプレビューでも、Test values のスライダーを動かすと実際に線が推移する様子を確認できます。

## 12. 警告・エラーの読み方

Asset Editor は入力ミスに気付けるよう、その場で警告やエラーを表示します。

| 表示 | 意味 | 対処 |
|---|---|---|
| 入力欄が赤枠 | `File`/`Bg` に指定したファイル名が、読み込んだフォルダの中に見つからない | ファイル名の綴りを確認するか、画像をフォルダに追加してください |
| 黄色い警告ボックス（不明なキー） | GUI が認識しないキーがそのセクションに存在する（typo の可能性） | キー名を確認してください。意図的な場合はそのままでも動作は継続します |
| 赤い警告ボックス（重複キー） | 同じキーがセクション内に 2 回以上書かれている | どちらか不要な行を右側のテキストエディタで削除してください |
| 右側のエラー表示 | layout.cfg の内容がそもそも読み込めない（必須項目の欠落・数値や色の形式ミスなど） | エラーメッセージにファイル名・セクション名・キー名・入力値が出ます。直るまで GUI 側の編集は無効化されますが、テキスト欄はそのまま編集できます |

## 13. 困ったときは

- 「Test values & diagnostics」内の **Check all fields** ボタンで、今読み込んでいる全セクション・全フィールドについて、テキストとの同期が正しく行われるかをまとめて確認できます
- 変更を試してから元に戻したい場合は、テキストエディタを直接編集して戻すか、保存前ならページを再読み込みしてください（保存前の変更は破棄されます）
- うまく反映されない場合は、まず該当パーツのセクションにチェックが入っているか（Active になっているか）を確認してください
