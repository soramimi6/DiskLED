# 機能

[English](EN/FEATURES.md)

## できること（第1版 / MVP）

- **CPU・物理メモリ・SWAP（ページファイル相当）** の使用率メーター（上昇は速く、下降は余韻）
- **ディスク** 読み書きの LED と速度バー（全物理ディスク合算）
- **ネットワーク** 送受信の LED と速度バー（実 NIC 合算。VPN・ループバック等は除外を試みる）
- **Ping** 応答の 4 段階表示（正常／やや遅い／遅い／タイムアウト）
- **表示モード切替**: Original / Crystal / Metalic
- Original / Metalic のフル表示では推移グラフ（**実測ベース**。更新間隔内の最大）。Original は棒、Metalic は折れ線。ネットの直線／対数切替時はクリア
- **最前面表示**・ウィンドウのドラッグ移動
- 本体（およびトレイ）にマウスを乗せると **版・使用率・Disk/Net I/O・Ping（先と RTT）** をツールチップ表示
- **単一起動**（2 つ目を起動すると既存ウィンドウを前面化して終了）
- **トレイアイコン**（起動中表示）・**スタートアップ登録**・設定の ini 保存
- **インストーラー**（ユーザー権限・アンインストール対応）とポータブル zip（詳細は [INSTALL.md](INSTALL.md)）

## 表示モード

アプリ同梱の見た目です。旧版のユーザー導入スキン（`.dla`）は使いません。

| モード | 由来（旧スキン） | サイズ目安 | 透過 |
|--------|------------------|------------|------|
| **Original** | System Analog Meter II（sam2）コンパクト相当 | 240×34 | あり |
| **Crystal** | Mac OS X 風（MacX） | 192×14 | あり |
| **Metalic** | xsrv SkinS | 256×24 | なし（矩形） |

- Original ではフル背景 `Original_FullBase.png` と推移グラフ矩形を `[ModeFull]` / `[Graph]` で定義（左ダブルクリックで切替）。ネット LED は送受信別（In / Out）。グラフは棒
- Crystal はフル定義なし（コンパクト固定）
- Metalic はフル背景 `Metalic_FullBase.bmp`＋グラフ（左ダブルクリックで切替）。グラフは折れ線

## 監視の考え方

| 対象 | 内容 |
|------|------|
| ディスク | システム全体の I/O 合算（本体 HDD ランプ相当）。個別ドライブ選択は対象外（第1版） |
| ネットワーク | 実 NIC の合算。特定 NIC 固定は対象外（第1版） |
| 速度レンジ | ネット: リンク速度。表示は直線（既定）または対数（オプション）。ディスク: 実測オートセンスの直線。手動レンジ UI は対象外 |
| Ping | 既定ホスト `mg6.jp`、またはデフォルトゲートウェイ自動（設定で切替予定）。間隔は最低・既定とも **5 分**。右クリック「Ping 更新」（日本語 UI 以外では Refresh Ping）で即時 1 回 |

### Ping 段階（既定閾値）

| 表示 | 条件（既定） |
|------|----------------|
| 正常 | 0 ≤ RTT &lt; 200 ms |
| やや遅い | 200 ≤ RTT &lt; 500 ms |
| 遅い | 500 ≤ RTT &lt; 1000 ms |
| タイムアウト | 失敗、または ≥ 1000 ms |

閾値はオプションで変更可能とする設計です（実装状況は CHANGELOG / DESIGN を参照）。
