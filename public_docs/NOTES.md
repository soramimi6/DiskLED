## 動作上の注意

- **Ping** は外部ホスト（既定 `mg6.jp`）またはゲートウェイへ ICMP を送ります。オプションでオフにできます。セキュリティソフトやファイアウォールが ICMP を遮断していると、常にタイムアウト表示になります（仕様として許容）
- **ディスク／ネット** は合算表示です。特定ドライブや特定 NIC だけを見る機能はありません
- 仮想アダプタ除外はヒューリスティックです。環境によって LED が点きやすい／点きにくい場合があります
- 高 DPI: 3.1.0 から **Per-Monitor V2**。ガジェットの表示倍率は 0.5 刻みのため OS 倍率と一致しないことがあります（**125% は見た目 150%**）。スキン画像は拡大でやや荒れることがあります。ダッシュボードは実 DPI に合わせます。以前の版で保存したダッシュボードの位置・サイズが大きすぎる場合は、一度サイズを直してください
- 表示の動きはおおむね **10〜20 fps**（既定 15 fps）です。負荷軽減のため見た目のコマが変わらないときは再描画しません
- ネットの実 NIC 一覧は数秒ごとに更新します。VPN 接続などですぐには LED に乗らない／残ることがあります
- ダッシュボードの CPU サブセクションに **温度等の高度な情報は出しません**。一般権限の Windows API では CPU 情報を安定して取れないためです
- ダッシュボードのメモリバー「スタンバイ」はタスク マネージャのスタンバイ一覧そのものではなく、利用可能メモリのうちキャッシュ相当を近似しています
- ダッシュボードの配色は Windows の「アプリのモード」（ライト／ダーク）に合わせます。ガジェット本体の表示モード（Original / Crystal / Metalic / Info Bar / Vintage）はスキン固定で、OS の明暗には連動しません。オプション画面（3.2.0 から）も Windows のライト／ダークに追従します
- **GPU 使用率**（3.2.0、ダッシュボード CPU カードに同居）: 複数 GPU 搭載機では最もビジーな GPU の使用率を表示します。GPU カウンタが無い環境（古い Windows、RDP セッション等）では 0 表示にフォールバックします
- 再生デバイスへ送られているミックスの **L / R ピーク**（0〜1）を端末内で読み、全チャンネルの最大をモノラル相当としても持ちます。波形・録音は保持しません。ダッシュボードの電源サブセクション右枠に、左から右へ点灯する横向き L / R バーと、既定再生デバイスの表示名（端末内のみ）を出します。他アプリが排他モードのときはピークが 0 になり、再生デバイスが無いときはピークは 0・名前は — です
- **タスクトレイ**（3.1.1、3.2.0 で「ウィンドウのみ／ウィンドウ＋トレイ LED／トレイ LED のみ」の3択に刷新）: 通知領域の「隠れているアイコン」に格納すると、トレイ LED の点灯・消灯が見えなくなります（Windows の仕様）。ユーザー自身の操作により常に見える位置へのピン留めを推奨します。トレイアイコンの表示位置・並び順（メイン領域／オーバーフロー）は Windows シェル側の管理で、DiskLED からは制御できません
- **Microsoft Store 版**（3.1.1）: 起動時の GitHub 更新確認は行いません（Store 経由で自動更新されるため）。GitHub 版のインストーラー／ポータブル zip と併用しないでください。両方入れると二重起動や `DiskLED.ini` の設定の取り合いが起きる場合があります。GitHub 版から Store 版へ切り替える場合は、先に GitHub 版をアンインストール（ポータブル版はフォルダごと削除）してから Store 版を導入してください。「スタートアップに登録」は 3.1.2 から Windows の起動タスク機構経由で正しく動作します（3.1.1 以前は登録が反映されない不具合がありました）。Windows 側で無効化されている場合はオプション画面にその旨を表示します

## 旧 DiskLED 2.x から変わったこと

| 項目 | 2.x | 3.x（本シリーズ） |
|------|-----|-------------------|
| 対象 OS | 95〜XP など | Windows 10 / 11 |
| スキン | ユーザー配布 `.dla` など | 同梱表示モードのみ（layout.cfg）。3.2.0 から同梱のブラウザ版ツール「Asset Editor」で、同じ形式のオリジナル表示モードを自作可能（詳細は [SKIN_GUIDE.md](SKIN_GUIDE.md)） |
| 推移グラフ | sam2 フル等 | Original / Metalic のフル表示（ダブルクリック）。Crystal はコンパクトのみ、Info Bar・Vintage はフル表示ありだが推移グラフ非対応 |
| サウンド | あり | ダッシュボードの電源サブセクション右枠（横向き L / R と出力先名）。ガジェットは `layout.cfg` の `Audio` / `AudioL` / `AudioR` で出せる（同梱では Info Bar が L / R を使用） |
| フローティング | あり | **非対応** |
| SSTP | あり | **非対応** |
| 複数起動 | 条件により可 | **単一起動のみ** |
| 言語 | リソースにより可変 | **OS UI 連動が既定（英語、日本語 UI のときだけ日本語）。3.2.0 からオプションで Auto／日本語／English を手動選択も可能（次回起動から反映）** |

## 収集しない／しないこと

- 広告の表示、無断での他ソフト導入は行いません
- 個人情報の収集・送信を目的とした通信は行いません
- 定期的な外部送信は **Ping**（先とオン／オフはオプション）と、起動時 1 回の **GitHub Releases Latest**（新しい版の確認。オプションでオフ）だけです。版番号以外の個人情報は付けません
- マイク入力は使いません。再生ミックスの L / R / モノラル相当ピーク以外の音声データは取りません
