## 動作上の注意

- **Ping** は外部ホスト（既定 `mg6.jp`）またはゲートウェイへ ICMP を送ります。オプションでオフにできます。セキュリティソフトやファイアウォールが ICMP を遮断していると、常にタイムアウト表示になります（仕様として許容）
- **ディスク／ネット** は合算表示です。特定ドライブや特定 NIC だけを見る機能はありません（第1版）
- 仮想アダプタ除外はヒューリスティックです。環境によって LED が点きやすい／点きにくい場合があります
- 高 DPI: 3.1.0 から **Per-Monitor V2**。ガジェットは 0.5 刻みのため OS 倍率と一致しないことがあります（**125% は見た目 150%**）。スキン画像は拡大でやや荒れることがあります。ダッシュボードは実 DPI に合わせます。以前の版で保存したダッシュボードの位置・サイズが大きすぎる場合は、一度サイズを直してください
- 表示の動きはおおむね **10〜20 fps**（既定 15 fps）です。見た目のコマが変わらないときは再描画しません
- ネットの実 NIC 一覧は数秒ごとに更新します。VPN 接続などですぐには LED に乗らない／残ることがあります
- ダッシュボードの CPU サブセクションに **パッケージ温度は出しません**。一般権限の Windows API では CPU 温度を安定して取れないためです
- ダッシュボードのメモリバー「スタンバイ」はタスク マネージャのスタンバイ一覧そのものではなく、利用可能メモリのうちキャッシュ相当を近似しています
- ダッシュボードの配色は Windows の「アプリのモード」（ライト／ダーク）に合わせます。ガジェット本体の表示モード（Original / Crystal / Metalic / Info Bar）はスキン固定で、OS の明暗には連動しません。ライト側の色は暫定です
- 再生デバイスへ送られているミックスの **L / R ピーク**（0〜1）を端末内で読み、全チャンネルの最大をモノラル相当としても持ちます。波形・録音は保持しません。ダッシュボードの電源サブセクション右枠に、左から右へ点灯する横向き L / R バーと、既定再生デバイスの表示名（端末内のみ）を出します。他アプリが排他モードのときはピークが 0 になり、再生デバイスが無いときはピークは 0・名前は — です

## 旧 DiskLED 2.x から変わったこと

| 項目 | 2.x | 3.x（本シリーズ） |
|------|-----|-------------------|
| 対象 OS | 95〜XP など | Windows 10 / 11 |
| スキン | ユーザー配布 `.dla` など | 同梱表示モードのみ（layout.cfg） |
| 推移グラフ | sam2 フル等 | Original / Metalic のフル表示（ダブルクリック）。Crystal / Info Bar はコンパクトのみ |
| サウンド | あり | ダッシュボードの電源サブセクション右枠（横向き L / R と出力先名）。ガジェットは `layout.cfg` の `Audio` / `AudioL` / `AudioR` で出せる（同梱では Info Bar が L / R を使用） |
| フローティング | あり | **非対応** |
| SSTP | あり | **非対応** |
| 複数起動 | 条件により可 | **単一起動のみ** |
| 言語 | リソースにより可変 | **OS UI 連動（既定は英語、日本語 UI のときだけ日本語）** |

## 収集しない／しないこと

- 広告の表示、無断での他ソフト導入は行いません
- 個人情報の収集・送信を目的とした通信は行いません
- Ping 以外の定期的な外部送信はありません（Ping 先とオン／オフはオプションで変えられます）
- マイク入力は使いません。再生ミックスの L / R / モノラル相当ピーク以外の音声データは取りません
