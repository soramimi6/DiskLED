## 動作上の注意

- **Ping** は外部ホスト（既定 `mg6.jp`）またはゲートウェイへ ICMP を送ります。セキュリティソフトやファイアウォールが ICMP を遮断していると、常にタイムアウト表示になります（仕様として許容）
- **ディスク／ネット** は合算表示です。特定ドライブや特定 NIC だけを見る機能はありません（第1版）
- 仮想アダプタ除外はヒューリスティックです。環境によって LED が点きやすい／点きにくい場合があります
- 高 DPI（125% 超など）では表示がぼやけたり位置がずれることがあります（第1版は 100% 前提）
- 表示の更新はおおむね **10〜20 fps**（既定 15 fps）です。計測そのものがシステムに大きな負荷をかけないよう設計しています

## 旧 DiskLED 2.x から変わったこと

| 項目 | 2.x | 3.x（本シリーズ） |
|------|-----|-------------------|
| 対象 OS | 95〜XP など | Windows 10 / 11 |
| スキン | ユーザー配布 `.dla` など | 同梱表示モードのみ（layout.cfg） |
| 推移グラフ | sam2 フル等 | Original / Metalic のフル表示（ダブルクリック）。Crystal はコンパクトのみ |
| サウンド | あり | **非対応** |
| フローティング | あり | **非対応** |
| SSTP | あり | **非対応** |
| 複数起動 | 条件により可 | **単一起動のみ** |
| 言語 | リソースにより可変 | **OS UI 連動（既定は英語、日本語 UI のときだけ日本語）** |

## 収集しない／しないこと

- 広告の表示、無断での他ソフト導入は行いません
- 個人情報の収集・送信を目的とした通信は行いません
- Ping 以外の定期的な外部送信はありません（Ping 先は設定で変えられる設計です）
