# 使い方

[English](EN/USAGE.md)

## 起動と終了

1. インストール先（またはポータブル展開先）の `DiskLED.exe` を実行します
2. デスクトップにメーターウィンドウが表示されます
3. 終了するときは、ウィンドウ上で **右クリック** → **終了**（日本語 UI 以外では **Exit**）を選びます

- 二重起動はできません。すでに起動中なら既存のウィンドウを前面に出して、新しいプロセスは終了します
- タスクマネージャーでの強制終了は避けてください（通常の「終了」メニューを使ってください）
- 通常終了時、スタートアップ登録を現在のオプションに合わせて書き直します（exe の場所が変わっていればパスも更新します）

## ウィンドウ操作


| 操作       | 内容                                         |
| -------- | ------------------------------------------ |
| 左ドラッグ    | ウィンドウの移動                                   |
| マウスを乗せる  | ツールチップで版、CPU / MEM / SWP、Disk / Net I/O、Ping（先と RTT）。内容は約 1 秒ごとに更新 |
| 左ダブルクリック | コンパクト ⇄ フル（Original / Metalic。Crystal / Info Bar は無効） |
| 右クリック    | ポップアップメニュー                                 |


タスクバーには出ない常駐ツールウィンドウとして動作します（常駐ガジェットとしての挙動です）。

## 右クリックメニュー（現状の実装）


| 項目                           | 内容                            |
| ---------------------------- | ----------------------------- |
| Original / Crystal / Metalic / Info Bar | 表示モード切替（排他選択）                 |
| コンパクト / Compact              | コンパクト表示（常に選択可）                |
| フル / Full                    | フル表示（モードにフル定義があるときのみ有効）       |
| タスクトレイ / Task Tray          | 表示サイズをタスクトレイに（コンパクト・フルと排他選択）。詳細は [タスクトレイ](#タスクトレイ) 節 |
| ダッシュボード / Dashboard        | 左カラムと右カラムの別ウィンドウ。位置・サイズ・最大化を記憶。終了時に開いていれば次回も開く |
| Ping 結果表示 / View Trace Route | 経路（Tracert）の結果を専用ウィンドウで表示。詳細は [Ping 結果表示](#ping-結果表示) 節 |
| オプション / Options              | 最前面・スタートアップ・起動時の版確認・fps・グラフ更新・ネット速度の反応（直線／対数）・Ping 設定 |
| 位置をリセット / Reset Position   | 本体ウィンドウを画面内へ収まる位置に戻して前面化する。画面外に外れて操作できなくなったときの復旧用（タスクトレイ中でも使え、コンパクト／フルへ復帰する） |
| 新しい DiskLED 3.x.x の情報を見る / View DiskLED 3.x.x release info | 手元より新しい安定版があるときだけ、終了の直上に出す。クリックでその GitHub リリースページを開く（入れるまで毎起動）。トレイ通知は同じ版で 1 回だけ |
| 終了 / Exit                    | アプリ終了                         |


メニュー文言は OS の UI 言語に連動します（**既定は英語**、日本語 UI のときだけ日本語）。右クリックメニューは表示サイズ（コンパクト／フル／タスクトレイ）によらずトレイアイコンからも本体からも同じものが出ます。トレイにマウスを乗せると、本体と同じツールチップ内容（版、使用率、I/O、Ping）が出ます。

## タスクトレイ

右クリックメニューの表示サイズを **タスクトレイ** にすると、本体ウィンドウが画面から消えます（アプリは終了しません）。代わりに通知領域のアイコンが、ディスクの読み書き有無を示す LED として点灯・消灯します（読取と書込は区別しません）。

- コンパクト・フルへ戻すには、トレイアイコンを **ダブルクリック** するか、右クリックメニューから **コンパクト** / **フル** を選びます。直前に使っていたコンパクト／フルへ戻ります
- 右クリックメニューはコンパクト・フル中と同じもので、表示サイズの変更やダッシュボードを開く操作もそのまま行えます
- ダッシュボードは表示サイズと独立しています。タスクトレイ中でも、開いていればそのまま表示され続けます
- 通知領域の「隠れているアイコン」に格納すると、点灯・消灯が見えなくなります（Windows の仕様）。常に見える位置にピン留めすることをおすすめします
- 表示モードごとに専用の LED 画像を用意していますが、用意が無い場合はアプリアイコン固定（点灯しない）にフォールバックします

## Ping 結果表示

右クリックメニューの **Ping 結果表示**（日本語 UI 以外では **View Trace Route**）で専用ウィンドウを開きます。宛先までの経路を Tracert のように 1 ホップずつ、近い方から順に表示します。

- 上部にホップ数・合計時間・最終計測日時を表示
- リストは TTL・IP・ホスト名・RTT の列。ホスト名解決は非同期で行われ、判明した時点でリストに反映されます
- 到達できない場合や名前解決・通信の初期化に失敗した場合は、その旨を表示します
- **Ping/経路 更新** ボタンで再計測します。ウィンドウを閉じても内容は保持され、次に開いたときに再計測します
- ウィンドウの配色は Windows のライト／ダークに連動します

## 表示の見方（共通）

- **メーター** … CPU / メモリ / SWAP などの使用率。上昇は速く、下降は余韻あり（表示モードにより差がある）
- **LED** … ディスク読み書き・ネット送受信の活動有無（Original は In / Out 個別。Crystal 等は統合の活動 LED もある）。Info Bar は活動 LED を出さず、速度を横向き LED バーで示す
- **速度バー** … 瞬間速度。ディスクはオートセンスの直線。ネットはオプションで直線または対数（上昇は速く、下降は余韻）
- **Ping** … 4 段階の枠／ランプ（モードにより見た目が異なります）
- **音量** … Info Bar のみ、再生ピークの L / R を横向き LED バーで表示（ダッシュボードの電源サブセクション右枠とは別）

モードごとのパーツ配置は各表示モードの見た目に従います。Original / Metalic はフル表示で推移グラフを描画します（**実測の正規化値**。各点はグラフ更新間隔内の最大。メーターの余韻は含みません）。Original は棒、Metalic は折れ線です。ネット速度の直線／対数を切り替えると、物差しが変わるのでグラフはクリアされます。

## ダッシュボード（3.1.0）

右クリックメニューの **ダッシュボード** から別ウィンドウを開きます。画面の呼び方は次のとおりです。

```
DISKLED HUD（ヘッダー）
+ 左カラム
| + CPU / メモリ / SWAP / ディスク / ネットの各セクション
|     ドーナツグラフ（約 5 回／秒） | 履歴グラフ（直近約 5 分、1 秒ごとに更新）
+ 右カラム
  + CPUサブセクション … 名前・コア（C/T）・クロック（現在／最大が離れているときは両方）・User/Kernel
  + メモリサブセクション … RAM は使用中／スタンバイ／空きの積み上げバー、SWAP は使用量とコミット
  + 電源サブセクション … 左枠：ソース（AC／バッテリ）、バッテリ残量、残時間（項目名は AC 接続中も表示。値が取れないときは —）。右枠：再生音量の横向き L / R セグメントバー（左から右。0–70% 緑、70–90% 黄、90–100% 赤。上昇は速く下降はやや遅い）と、その下に出力先名 1 行（入り切らなければ …。取れないときは —）
  + ディスク情報 … キュー長とレイテンシ（平均応答時間、ms。取得できないときは —）を並べた大きな数字、全ドライブ合算のアクティブ時間、読取／書込 IOPS
  + Ping … 直近の RTT／宛先と、時刻・宛先・RTT・状態の履歴（最大 5 件、新しい順）
```

- ディスクセクションは読取（外側リング）と書込（内側リング）をまとめ、履歴はどちらも実線（色と凡例で区別）。ネットの受信／送信も同様
- ドーナツ中央の数字は 1 秒ごと。リングの動きと音量バーだけ約 5 回／秒で追従する
- CPU / メモリ / SWAP の履歴グラフは折れ線の下を、線より薄い色で塗りつぶす。ディスク／ネットは線が重なるため塗りつぶしなし
- × で閉じると非表示（履歴はメモリに残る）。位置・サイズ・最大化は閉じても残る。終了時に開いたままなら、次回起動でも同じ状態で開きます（ini のサイズは 96dpi 換算）。再起動で履歴は消えます
- CPU パッケージ温度は出しません（一般権限では安定して取れません）
- 左右の同じ段は同じ高さ（CPU／メモリ／SWAP↔電源／ディスク↔ディスク情報／ネット↔Ping）。スクロールなしで 1 画面に収まる配置。ウィンドウはリサイズ可
- 配色は Windows の「アプリのモード」（ライト／ダーク）に合わせます。OS 側で切り替えると、開いているダッシュボードにも反映されます。ライト側の色は暫定です
- タスクバーに表示されます（ガジェット本体は従来どおり非表示）
- Ping をオプションでオフにすると、ツールチップは「オフ」。ダッシュボードの Ping サブセクションは新規送信せず、直近の履歴を残します

## オプション

右クリックの **オプション**（日本語 UI 以外では **Options**）。確定は **適用**（キャンセルで破棄）。

| 項目 | 内容 |
|------|------|
| 常に手前に表示 | ガジェット本体の最前面（既定オン）。ダッシュボードは対象外 |
| スタートアップに登録 | ログオン時に起動。適用時と通常終了時に Run キーへ書き込む |
| 起動時に新しい版を確認する | 起動後に GitHub の Latest を 1 回見る（既定オン）。オフで通信もメニューも出さない。Microsoft Store 版では Store 経由で自動更新されるためこの項目自体が出ません。**Store 版と GitHub 版（インストーラー／zip）は併用しないでください** |
| 表示頻度 (fps) | 10 / 15（既定）/ 20。見た目のコマが変わらないときは再描画しない |
| グラフ更新 (Hz) | 0.5 / 1（既定）/ 2。Original / Metalic **フル表示**の推移グラフ。ダッシュボードの履歴は常に 1 秒 |
| ネット速度の反応 | 直線（リンク速度＝100%、既定）または対数。切替時はガジェットとダッシュボードのネット履歴をクリア |
| Ping を有効にする | オフで定期 ICMP を止める |
| デフォルトゲートウェイを使う | オンのときホスト欄は編集不可 |
| Ping ホスト | 既定 `mg6.jp`（ゲートウェイオフのとき） |
| 間隔 | 秒。**最低・既定 300**（5 分） |
| Ping 判定しきい値 | やや遅い / 遅い / タイムアウト (ms)。やや遅い ＜ 遅い ＜ タイムアウト。既定 200 / 500 / 1000 に戻すボタンあり |

## 設定ファイル

設定は通常、実行ファイルと同じ場所の `DiskLED.ini` に保存します。Program Files などへ書き込めない場合は `%AppData%\DiskLED\DiskLED.ini` を使います。手編集する場合はアプリ終了後に行ってください。ダッシュボードの位置・サイズは 96dpi の DIP で保存し、最大化は別キーです。起動時にそのモニタの DPI で物理ピクセルへ直します。
