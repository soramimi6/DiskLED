# 使い方

[English](EN/USAGE.md)

## 起動と終了

1. インストール先（またはポータブル展開先）の `DiskLED.exe` を実行します
2. デスクトップにメーターウィンドウが表示されます
3. 終了するときは、ウィンドウ上で **右クリック** → **終了**（日本語 UI 以外では **Exit**）を選びます

- 二重起動はできません。すでに起動中なら既存のウィンドウを前面に出して、新しいプロセスは終了します
- タスクマネージャーでの強制終了は避けてください（通常の「終了」メニューを使ってください）

## ウィンドウ操作


| 操作       | 内容                                         |
| -------- | ------------------------------------------ |
| 左ドラッグ    | ウィンドウの移動                                   |
| マウスを乗せる  | ツールチップで版、CPU / MEM / SWP、Disk / Net I/O、Ping（先と RTT）。内容は約 1 秒ごとに更新 |
| 左ダブルクリック | コンパクト ⇄ フル（Original / Metalic。Crystal は無効） |
| 右クリック    | ポップアップメニュー                                 |


タスクバーには出ない常駐ツールウィンドウとして動作します（常駐ガジェットとしての挙動です）。

## 右クリックメニュー（現状の実装）


| 項目                           | 内容                            |
| ---------------------------- | ----------------------------- |
| Original / Crystal / Metalic | 表示モード切替（排他選択）                 |
| コンパクト / Compact              | コンパクト表示（常に選択可）                |
| フル / Full                    | フル表示（モードにフル定義があるときのみ有効）       |
| Ping 更新 / Refresh Ping       | すぐに 1 回 Ping を送る              |
| オプション / Options              | 最前面・スタートアップ・fps・グラフ更新・Ping 設定 |
| 終了 / Exit                    | アプリ終了                         |


メニュー文言は OS の UI 言語に連動します（**既定は英語**、日本語 UI のときだけ日本語）。トレイにアイコンを出しますが本体の格納はしません（右クリックは本体と同じメニュー、ダブルクリックで前面化）。トレイにマウスを乗せても、本体と同じツールチップ内容（版、使用率、I/O、Ping）が出ます。

## 表示の見方（共通）

- **メーター** … CPU / メモリ / SWAP などの使用率。上昇は速く、下降は余韻あり（表示モードにより差がある）
- **LED** … ディスク読み書き・ネット送受信の活動有無（Original は In / Out 個別。Crystal 等は統合の活動 LED もある）
- **速度バー** … 瞬間速度（レンジは自動。上昇は速く、下降は余韻）
- **Ping** … 4 段階の枠／ランプ（モードにより見た目が異なります）

モードごとのパーツ配置は旧スキンを踏襲しています。Original / Metalic はフル表示で推移グラフを描画します（**実測の正規化値**。各点はグラフ更新間隔内の最大。メーターの余韻は含みません）。

## 設定ファイル

設定は通常、実行ファイルと同じ場所の `DiskLED.ini` に保存します。Program Files などへ書き込めない場合は `%AppData%\DiskLED\DiskLED.ini` を使います。手編集する場合はアプリ終了後に行ってください。
