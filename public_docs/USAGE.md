# 使い方

[English](EN/USAGE.md)

## 起動と終了

1. スタートメニューから DiskLED を選択し、起動します。ポータブル版の場合はインストール先の `DiskLED.exe` を実行します
2. デスクトップにメーターウィンドウが表示されます
3. 終了するときは、ウィンドウ上で **右クリック** → **終了**（日本語 UI 以外では **Exit**）を選びます

- 二重起動はできません。すでに起動中なら既存のウィンドウを前面に出して、新しいプロセスは終了します
- タスクマネージャーでの強制終了は避けてください（通常の「終了」メニューを使ってください）
- 通常終了時、スタートアップ登録を現在のオプションに合わせて書き直します（exe の場所が変わっていればパスも更新します）

## ウィンドウ操作


| 操作       | 内容                                         |
| -------- | ------------------------------------------ |
| 左ドラッグ    | ウィンドウの移動                                   |
| マウスを乗せる  | ツールチップで版、CPU / MEM / SWP、Disk / Net I/O、Ping（先と RTT）。内容は約 1 秒ごとに更新 |
| 左ダブルクリック | コンパクト ⇄ フル（Original / Metalic / Vintage / Info Bar。Crystal は無効） |
| 右クリック    | ポップアップメニュー                                 |


タスクバーには出ない常駐ツールウィンドウとして動作します（常駐ガジェットとしての挙動です）。

## タスクトレイ

オプションの **全般** タブの **表示モード**（**ウィンドウのみ／ウィンドウ＋トレイ LED／トレイ LED のみ**）で、本体ウィンドウの表示とトレイ LED の点灯を選びます（コンパクト／フルの表示サイズとは別軸）。

- **ウィンドウのみ**（既定）: 本体ウィンドウだけを表示し、トレイ LED は点灯しません
- **ウィンドウ＋トレイ LED**: 本体ウィンドウを表示したまま、通知領域のアイコンもディスク・ネットワークの活動 LED として同時に点灯します
- **トレイ LED のみ**: 本体ウィンドウを画面から消し（アプリは終了しません）、通知領域のアイコンだけを LED として点灯・消灯します
- トレイアイコンを **クリック** するとダッシュボードを開きます。**ダブルクリック** すると本体ウィンドウを表示します（トレイ LED のみの状態からも戻ります）
- 右クリックメニューはどの状態でも同じもので、オプションやダッシュボードもそこから開けます
- ダッシュボードは表示状態と独立しています。トレイ LED のみの状態でも、開いていればそのまま表示され続けます
- ネットの LED は、通信が続いている間も転送量が下がった瞬間に一瞬消え、アクセスランプのようにちらつきます
- 通知領域の「隠れているアイコン」に格納すると、点灯・消灯が見えなくなります（Windows の仕様）。常に見える位置にピン留めすることをおすすめします

### トレイ LED の設定（オプション）

オプション画面の **トレイ LED** タブで次を設定します。

| 項目 | 内容 |
|------|------|
| トレイ LED の色 | 緑／青／赤／黄から、ディスクとネットワークで別々に選択 |
| トレイ LED の情報 | ディスク／ネットワークを独立したチェックボックスで選択。**両方同時 ON も可能**で、その場合はトレイアイコンが2つになり、一方がディスク・もう一方がネットワークの活動を表示する。両方 OFF にはできない |
| ドライブ別 LED | チェックしたドライブ（C: や D: など）ごとにトレイアイコンを出す。アイコン右下の文字とツールチップ（直近 1 秒の読込／書込の速度）で見分ける。未接続のドライブも選んでおけば、接続したときに表示する。光学ドライブは選べない |
| 合算 LED も表示する | ドライブ別 LED を選んでいるときも、全ドライブ合算のディスク LED を出す（既定オン） |

## 表示の見方（共通）

- **メーター** … CPU / メモリ / SWAP などの使用率。上昇は速く、下降は余韻あり（表示モードにより差がある）
- **LED** … ディスク読み書き・ネット送受信の活動有無（Original は In / Out 個別。Crystal 等は統合の活動 LED もある）。ネットの LED は、通信が続いている間も転送量が下がった瞬間に一瞬消える。Info Bar のフルは活動 LED を出さず速度を横向き LED バーで示すが、コンパクトは活動 LED（読取・受信＝緑、書込・送信＝赤）で示す
- **速度バー** … 瞬間速度。ディスクはオートセンスの直線。ネットはオプションで直線または対数（上昇は速く、下降は余韻）
- **Ping** … 4 段階の枠／ランプ（モードにより見た目が異なります）
- **音量** … Info Bar のみ、再生ピークの L / R を横向き LED バーで表示（ダッシュボードの電源サブセクション右枠とは別）

モードごとのパーツ配置は各表示モードの見た目に従います。Original / Metalic はフル表示で推移グラフを描画します（**実測の正規化値**。各点はグラフ更新間隔内の最大。メーターの余韻は含みません）。Original は棒、Metalic は折れ線です。ネット速度の直線／対数を切り替えると、物差しが変わるのでグラフはクリアされます。

## ダッシュボード（3.1.0）

右クリックメニューの **ダッシュボード**（またはトレイアイコンのクリック）から別ウィンドウを開きます。

ヘッダーの下のタブで **概要**・**プロセス**・**Ping/経路** の 3 ページを切り替えます（Ctrl+Tab／Ctrl+Shift+Tab でも切り替え可能）。ダッシュボードは常に概要ページで開きます。ヘッダーの右側には、PC の稼働時間と、ディスク（読込／書込）・ネット（受信／送信）の累計量を表示します（3.3.0）。

### 概要ページ

画面の呼び方は次のとおりです。

```
DISKLED HUD（ヘッダー）
+ 左カラム
| + CPU（GPU 同居）/ メモリ / SWAP / ディスク / ネットの各セクション
|     ドーナツグラフ（約 5 回／秒） | 履歴グラフ（直近約 5 分、1 秒ごとに更新）
+ 右カラム
  + CPUサブセクション … 名前・コア（C/T）・クロック（現在／定格が離れているときは両方。現在のクロックが取れないときは定格のみ）・ユーザー/カーネル
  + メモリサブセクション … RAM は使用中／スタンバイ／空きの積み上げバー、SWAP（ページファイル）は使用量とコミット
  + 電源サブセクション … 左枠：ソース（AC／バッテリ）、バッテリ残量、残時間（項目名は AC 接続中も表示。値が取れないときは —）。右枠：再生音量の横向き L / R セグメントバー（左から右。0–70% 緑、70–90% 黄、90–100% 赤。上昇は速く下降はやや遅い）と、その下に出力先名 1 行（入り切らなければ …。取れないときは —）
  + ディスク情報 … キュー長とレイテンシ（平均応答時間、ms。取得できないときは —）を並べた大きな数字、全ドライブ合算のアクティブ時間、読取／書込 IOPS
  + Ping … 直近の RTT／宛先と、時刻・宛先・RTT・状態の履歴（最大 5 件、新しい順）。クリックで Ping/経路ページへ移る
```

- CPU セクションは外側リングが CPU、内側リングが GPU（履歴は2本線、凡例で区別）。複数 GPU 搭載機では最もビジーな GPU の使用率を表示
- ディスクセクションは読取（外側リング）と書込（内側リング）をまとめ、履歴はどちらも実線（色と凡例で区別）。ネットの受信／送信も同様
- ドーナツ中央の数字は 1 秒ごと。リングの動きと音量バーだけ約 5 回／秒で追従する。CPU は直近 1 秒の平均（タスクマネージャーと同じ基準）、ディスク・ネットの速度も直近 1 秒の平均。ネットの速度はビット単位（Kbps／Mbps／Gbps）
- SWAP はページファイルの使用率。値が取れない環境では — を表示
- CPU / メモリ / SWAP の履歴グラフは折れ線の下を、線より薄い色で塗りつぶす。ディスク／ネットは線が重なるため塗りつぶしなし
- × で閉じると非表示（履歴はメモリに残る）。位置・サイズ・最大化は閉じても残る。終了時に開いたままなら、次回起動でも同じ状態で開きます（ini のサイズは 96dpi 換算）。再起動で履歴は消えます
- CPU パッケージ温度は出しません（一般権限では安定して取れません）
- 左右の同じ段は同じ高さ（CPU／メモリ／SWAP↔電源／ディスク↔ディスク情報／ネット↔Ping）。スクロールなしで 1 画面に収まる配置。ウィンドウはリサイズ可
- 配色は Windows の「アプリのモード」（ライト／ダーク）に合わせます。OS 側で切り替えると、開いているダッシュボードにも反映されます。ライト側の色は暫定です
- タスクバーに表示されます（ガジェット本体は従来どおり非表示）
- Ping をオプションでオフにすると、ツールチップは「オフ」。ダッシュボードの Ping サブセクションは新規送信せず、直近の履歴を残します

### プロセスページ

CPU 使用率・メモリ使用量・I/O 量のそれぞれについて、使っている量の多いプロセスを左から 3 列で表示します（3.3.0）。

- 同じ名前のプロセスはまとめて 1 行にし、名前の後ろに件数を付けます（例 `chrome (12)`）
- 1 件は「アイコン・名前・値」「ウィンドウのタイトル（無ければ説明・製品名）と会社名」「実行ユーザー・コミット・ハンドル数・スレッド数」「実行ファイルのパス」の 4 行。マウスを乗せると、バージョン・64bit／32bit・著作権を加えた詳細を表示します
- CPU は全体に対する割合、メモリは使用量（プライベート ワーキング セット）と物理メモリに対する割合、I/O は読込・書込の速度。I/O はファイル・ネットワーク・デバイスへの読み書きをすべて含むため、タスクマネージャーの「ディスク」列とは一致しません
- システムのプロセスや管理者権限で動いているプロセスなど、DiskLED から開けないプロセスは「詳細を取得できません」と表示し、既定のアイコンにします
- ウィンドウを縦に広げると表示件数が増えます
- タブ行の右端で更新の間隔（3／5／10 秒）を選びます。「停止」を選ぶとその時点の一覧のまま止まります。選んだ間隔は記憶します（停止は記憶しません）
- 収集はこのページを表示している間だけ行います

### Ping/経路ページ

宛先までの往復時間が、経路上のどの区間でどれだけかかっているかを表示します（3.3.0。3.2.0 以前の「Ping 結果表示」ウィンドウの置き換え）。宛先は Ping の設定と同じです。

- 上部に、宛先・ホップ数・往復時間・計測時刻と、往復時間を区間ごとに色分けした内訳バー、各ホップのウォーターフォール（区間の横棒と最小〜最大の線）を表示します。グレーの破線は、ルーター自身の応答の遅れ（経路の遅延ではない分）です
- 下部の一覧は、ホップごとのホスト名（IP）・区分（LAN／CGNAT／グローバルなど）・応答の種類・損失・区間遅延・RTT（最小〜最大）・ジッター・前回比。行にマウスを乗せると詳細を表示します。入りきらないときはマウスホイールでスクロールします
- 1 回の計測では各ホップに 3 回ずつ送り、その中央値で比べます
- 計測はこのページを表示している間だけ行います。ページを開いたときに 1 回計測し、タブ行の右端で自動計測の間隔（1／5／10 分、既定は停止）を選べます。**今すぐ計測** でいつでも計測し直せます
- タブ行の **事業者名を表示** をオンにすると、グローバルアドレスのホップについて事業者名（例 `Example Corp. (AS64500)`）を外部の DNS サービスに問い合わせて表示します（既定オフ。問い合わせ先と送る内容は [NOTES.md](NOTES.md) を参照）
- Ping 先が IPv6 アドレスしか持たないときは IPv6 で計測します

## オプション

右クリックの **オプション**（日本語 UI 以外では **Options**）。確定は **適用**（キャンセルで破棄）。**全般／表示／トレイ LED／Ping・ネットワーク** の4タブに分かれます。見た目は Windows 標準で、ライト／ダークには追従しません（3.3.0）。

### 全般

| 項目 | 内容 |
|------|------|
| 常に手前に表示 | ガジェット本体の最前面（既定オン）。ダッシュボードは対象外 |
| スタートアップに登録 | ログオン時に起動。GitHub 版は適用時と通常終了時に Run キーへ書き込む。Microsoft Store 版は Windows の起動タスク機構（`windows.startupTask`）を使う。Windows 側（スタートアップ アプリ設定やポリシー）で無効化されている場合は操作不能になり、その旨を表示する |
| 起動時に新しい版を確認する | 起動後に GitHub の Latest を 1 回見る（既定オン）。オフで通信もメニューも出さない。Microsoft Store 版では Store 経由で自動更新されるためこの項目自体が出ません。**Store 版と GitHub 版（インストーラー／zip）は併用しないでください** |
| 表示言語 | Auto（既定）／日本語／English。**変更は次回起動から反映**されます |
| 表示モード | ウィンドウのみ（既定）／ウィンドウ＋トレイ LED／トレイ LED のみ。詳細は [タスクトレイ](#タスクトレイ) 節 |

### 表示

| 項目 | 内容 |
|------|------|
| 表示頻度 (fps) | 10 / 15（既定）/ 20。見た目のコマが変わらないときは再描画しない |
| グラフ更新 (Hz) | 0.5 / 1（既定）/ 2。Original / Metalic **フル表示**の推移グラフ。ダッシュボードの履歴は常に 1 秒 |
| ネット速度の反応 | 直線（リンク速度＝100%、既定）または対数。切替時はガジェットとダッシュボードのネット履歴をクリア |
| 表示倍率 | 自動（既定。画面 DPI 連動）／100%／150%／200%。ガジェット本体（スキン）の拡大率のみに効き、ダッシュボードには影響しない |

### トレイ LED

| 項目 | 内容 |
|------|------|
| トレイ LED の色 | 緑（既定）／青／赤／黄。ディスクとネットワークの行で別々に選ぶ |
| トレイ LED の情報 | ディスク／ネットワークの独立チェックボックス。両方同時 ON も可能（トレイアイコンが2つになる）。両方 OFF にはできない |
| ドライブ別 LED | ドライブの一覧から、トレイに個別の LED を出すドライブを選ぶ。未接続のドライブは「（未接続）」と表示 |
| 合算 LED も表示する | ドライブ別 LED を選んでいるときも、全ドライブ合算の LED を出す（既定オン） |

### Ping・ネットワーク

| 項目 | 内容 |
|------|------|
| Ping を有効にする | オフで定期 ICMP を止める |
| デフォルトゲートウェイを使う | オンのときホスト欄は編集不可 |
| Ping ホスト | 既定 `mg6.jp`（ゲートウェイオフのとき） |
| 間隔 | 秒。**最低・既定 300**（5 分） |
| Ping 判定しきい値 | やや遅い / 遅い / タイムアウト (ms)。やや遅い ＜ 遅い ＜ タイムアウト。既定 200 / 500 / 1000 に戻すボタンあり |

## 設定ファイル

設定は通常、実行ファイルと同じ場所の `DiskLED.ini` に保存します。Program Files などへ書き込めない場合は `%AppData%\DiskLED\DiskLED.ini` を使います。手編集する場合はアプリ終了後に行ってください。ダッシュボードの位置・サイズは 96dpi の DIP で保存し、最大化は別キーです。起動時にそのモニタの DPI で物理ピクセルへ直します。
