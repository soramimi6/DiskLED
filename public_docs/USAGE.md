# 使い方

[English](EN/USAGE.md)

## 起動と終了

1. インストール先（またはポータブル展開先）の `DiskLED.exe` を実行します
2. デスクトップにメーターウィンドウが表示されます
3. 終了するときは、ウィンドウ上で **右クリック** → **終了**（日本語 UI 以外では **Exit**）を選びます

- 二重起動はできません。すでに起動中なら既存のウィンドウを前面に出して、新しいプロセスは終了します
- タスクマネージャーでの強制終了は避けてください（通常の「終了」メニューを使ってください）
- 通常終了時、スタートアップ登録を現在のオプションに合わせて書き直します（exe の場所が変わっていればパスも更新します）

## ウィンドウ操作


| 操作       | 内容                                         |
| -------- | ------------------------------------------ |
| 左ドラッグ    | ウィンドウの移動                                   |
| マウスを乗せる  | ツールチップで版、CPU / MEM / SWP、Disk / Net I/O、Ping（先と RTT）。内容は約 1 秒ごとに更新 |
| 左ダブルクリック | コンパクト ⇄ フル（Original / Metalic。Crystal は無効） |
| 右クリック    | ポップアップメニュー                                 |


タスクバーには出ない常駐ツールウィンドウとして動作します（常駐ガジェットとしての挙動です）。

## 右クリックメニュー（現状の実装）


| 項目                           | 内容                            |
| ---------------------------- | ----------------------------- |
| Original / Crystal / Metalic | 表示モード切替（排他選択）                 |
| コンパクト / Compact              | コンパクト表示（常に選択可）                |
| フル / Full                    | フル表示（モードにフル定義があるときのみ有効）       |
| Ping 更新 / Refresh Ping       | すぐに 1 回 Ping を送る              |
| ダッシュボード / Dashboard        | 左カラムと右カラムの別ウィンドウ（3.1.0） |
| オプション / Options              | 最前面・スタートアップ・fps・グラフ更新・ネット速度の反応（直線／対数）・Ping 設定 |
| 終了 / Exit                    | アプリ終了                         |


メニュー文言は OS の UI 言語に連動します（**既定は英語**、日本語 UI のときだけ日本語）。トレイにアイコンを出しますが本体の格納はしません（右クリックは本体と同じメニュー、ダブルクリックで前面化）。トレイにマウスを乗せても、本体と同じツールチップ内容（版、使用率、I/O、Ping）が出ます。

## 表示の見方（共通）

- **メーター** … CPU / メモリ / SWAP などの使用率。上昇は速く、下降は余韻あり（表示モードにより差がある）
- **LED** … ディスク読み書き・ネット送受信の活動有無（Original は In / Out 個別。Crystal 等は統合の活動 LED もある）
- **速度バー** … 瞬間速度。ディスクはオートセンスの直線。ネットはオプションで直線または対数（上昇は速く、下降は余韻）
- **Ping** … 4 段階の枠／ランプ（モードにより見た目が異なります）

モードごとのパーツ配置は旧スキンを踏襲しています。Original / Metalic はフル表示で推移グラフを描画します（**実測の正規化値**。各点はグラフ更新間隔内の最大。メーターの余韻は含みません）。Original は棒、Metalic は折れ線です。ネット速度の直線／対数を切り替えると、物差しが変わるのでグラフはクリアされます。

## ダッシュボード（3.1.0）

右クリックメニューの **ダッシュボード** から別ウィンドウを開きます。画面の呼び方は次のとおりです。

```
DISKLED HUD（ヘッダー）
+ 左カラム
| + CPU / メモリ / SWAP / ディスク / ネットの各セクション
|     ドーナツグラフ | 履歴グラフ（直近約 5 分、1 秒ごとに更新）
+ 右カラム
  + CPUサブセクション … 名前・コア・クロック・User/Kernel
  + メモリサブセクション … RAM は使用中／スタンバイ／空きの積み上げバー、SWAP は使用量とコミット
  + 電源サブセクション … ソース（AC／バッテリ）、バッテリ残量、残時間（項目名は AC 接続中も表示。値が取れないときは —）
  + ディスクキュー … キュー長、全ドライブ合算のアクティブ時間、読取／書込 IOPS
  + Ping … 直近の RTT／宛先と、時刻・宛先・RTT・状態の履歴（最大 5 件、新しい順）
```

- ディスクセクションは読取（外側リング）と書込（内側リング）をまとめ、履歴はどちらも実線（色と凡例で区別）。ネットの受信／送信も同様
- CPU / メモリ / SWAP の履歴グラフは折れ線の下を、線より薄い色で塗りつぶす。ディスク／ネットは線が重なるため塗りつぶしなし
- CPU パッケージ温度は出しません（一般権限では安定して取れません）
- 左右の同じ段は同じ高さ（CPU／メモリ／SWAP↔電源／ディスク↔ディスクキュー／ネット↔Ping）。スクロールなしで 1 画面に収まる配置。ウィンドウはリサイズ可。× で閉じると非表示（履歴はメモリに残る）。再起動で履歴は消えます
- 配色は Windows の「アプリのモード」（ライト／ダーク）に合わせます。OS 側で切り替えると、開いているダッシュボードにも反映されます。ライト側の色は暫定です
- タスクバーに表示されます（ガジェット本体は従来どおり非表示）

## 設定ファイル

設定は通常、実行ファイルと同じ場所の `DiskLED.ini` に保存します。Program Files などへ書き込めない場合は `%AppData%\DiskLED\DiskLED.ini` を使います。手編集する場合はアプリ終了後に行ってください。
