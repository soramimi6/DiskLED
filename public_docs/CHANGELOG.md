# 変更履歴

[English](EN/CHANGELOG.md)

形式: 新しいものが上。ユーザー向けの要約のみ。

## 3.1.1

Windows 10 / 11 向け DiskLED 3.x の更新（64-bit）。

- **表示サイズに「タスクトレイ」を追加**。右クリックメニューの表示サイズが コンパクト／フル／タスクトレイ の排他 3 択になった。タスクトレイを選ぶと本体ウィンドウを画面から消し、通知領域のアイコン自体をディスクアクセス LED（読み書き統合の点灯／消灯）として表示。ダブルクリックで直前のコンパクト／フルへ復帰。
- **Ping 結果表示を専用ウィンドウに変更**（旧「Ping 更新」）。Tracert のようにホップごとの経路（TTL・IP・ホスト名・RTT）を上から順に表示する。ホップ数・合計時間に加え最終計測日時も表示
- **ダッシュボードにディスクのレイテンシ**（平均応答時間、ms）を追加。ディスク情報カードでキューと並んで数値表示
- ダッシュボードの最小サイズを 1000×900（96dpi DIP）に拡大
- Microsoft Store 版では起動時の GitHub 更新チェックを行わない（Store 経由で更新されるため）
- 右クリックメニューに **位置をリセット** を追加。画面外に外れて操作できなくなった本体ウィンドウを、トレイアイコンの右クリックから復旧できる
- アプリアイコンを刷新
-その他、不具合修正  
-  ホバーツールチップが画面外・マルチモニター境界をまたいで表示される問題表示のでの点滅を修
  -マルチ
- 環境で置いた状態で終了→再別なると、メン移動する場合があるせられていた具合を修正

## 3.1.0

Windows 10 / 11 向け DiskLED 3.x の更新（64-bit）。

- **高 DPI**: Per-Monitor V2。ガジェットは 0.5 刻み（1 / 1.5 / 2…。125% は見た目 1.5 倍）。ダッシュボードは実 DPI（Dpi/96）。オプションは VCL の Scaled
- **ダッシュボード**: 右クリックメニューから別ウィンドウを開く。左カラムは CPU / メモリ / SWAP / ディスク / ネットのセクション（ドーナツ＋履歴。ディスク・ネットは二重ドーナツと重ね折れ線、読取／書込・In／Out の色凡例付き）。右カラムは CPU 詳細、メモリ実量（使用中／スタンバイ／空きのバーと SWAP コミット）、電源（左枠：電源情報、右枠：左から右へ点灯する横向き L / R 音量セグメントバーと出力先名）、ディスクキュー（合算のアクティブ時間を含む）、Ping（直近と履歴最大 5 件）
- ダッシュボードは Windows のアプリのライト／ダークに合わせて配色する（設定の変更は開いている間にも反映）。表示中、左カラムのドーナツグラフと電源サブセクション右の音量バーは約 5 回／秒、数字・履歴・右カラムのほかは 1 秒ごとに更新。履歴はメモリ上のみ（再起動で消える）。終了時に開いていれば次回起動でも開く。位置・サイズ・最大化状態を復元（96dpi DIP）。CPU / メモリ / SWAP の履歴は折れ線の下を薄い色で塗りつぶす（ディスク／ネットは重ね線のため対象外）
- ダッシュボードの既定サイズを 960×720、最小を 800×600（96dpi DIP）にし、小さい画面でも収まりやすくした
- 再生出力の L / R ピークを内部で取得し、モノラル相当（全チャンネルの最大）も保持。ダッシュボードの電源サブセクション右枠に、左から右へ点灯する横向き L / R バーと出力先名（1 行・入り切らなければ …）を表示（波形・録音はしない）
- 左カラムのドーナツ中央の実数値を約 1.5 倍の大きさにし、CPU／メモリ／SWAP／ディスク／ネットすべてに黒縁を付けた
- ガジェットを画面端にスナップしたあと、端からドラッグで離れないことがあったのを修正
- 表示モード **Info Bar** を追加（531×16・コンパクトのみ）。CPU / メモリ / SWAP / ディスク読取・書込 / ネット送受信 / 再生音量 L / R を横向き LED バーで表示（活動 LED なし）
- 表示モード（`layout.cfg`）でガジェットに音量メーター `Audio` / `AudioL` / `AudioR`（0〜100%）を定義できる。同梱では **Info Bar** が L / R バーを使用（Original / Crystal / Metalic は未使用）
- オプション画面は高 DPI で自動スケール
- 起動時に GitHub Releases の Latest を 1 回確認。新しい安定版があればトレイ通知は版ごとに 1 回、右クリック（終了の直上）に「新しい DiskLED 3.x.x の情報を見る」を入れるまで出す。クリックでそのリリースページを開く（自動入手・入れ替えはしない。オプションでオフ可）
- 配布: `DiskLED_Setup_3.1.0.exe` と `DiskLED-3.1.0-portable.zip`

## 3.0.1

Windows 10 / 11 向け DiskLED 3.x の更新（64-bit）。

- 常駐負荷: 見た目のコマが変わったときだけ再描画（計測は表示 fps と同じ）
- メーター追従: 表示モードの `layout.cfg` `[Ballistic]` でプロファイル指定（vu / bar / peak）
- Original: ネット LED を送受信別（In / Out）に変更。アナログメーター 64 コマ。フル表示の推移グラフは棒
- Crystal: CPU / メモリ レベルバーを 32 コマに補間（滑らかな追従）
- Metalic: フル表示の推移グラフは折れ線（従来どおり）
- ネット速度の反応を直線（既定）と対数で切替可能（オプション）。ディスクはオートセンスの直線のみ。切替時は推移グラフをクリア
- 終了時にもスタートアップ登録を現在の設定へ合わせる（移動後の exe パス付け直しを含む）
- 配布: `DiskLED_Setup_3.0.1.exe` と `DiskLED-3.0.1-portable.zip`

## 3.0.0 — MVP

Windows 10 / 11 向けの DiskLED 3.x 初版（64-bit）。旧 2.x からの再構築です。

- CPU / メモリ / SWAP / ディスク / ネット / Ping の常駐表示
- 表示モード: Original / Crystal / Metalic（フル／コンパクト切替と推移グラフは Original・Metalic）
- 単一起動、最前面、トレイ、スタートアップ、オプション、`DiskLED.ini`
- ユーザー権限インストーラー（`DiskLED_Setup_3.0.0.exe`）とポータブル zip
- UI: 既定は英語、OS UI が日本語のときだけ日本語
- 広告・バンドルソフトなし
