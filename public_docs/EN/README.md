# DiskLED 3 — Public documentation

[日本語](../README.md)

A desktop-resident system monitor for Windows. See CPU, memory, disk, and network activity at a glance, plus reachability via Ping.

DiskLED 3 rebuilds the classic DiskLED series (2.x / Windows XP era) from the ground up for Windows 10 / 11.

An always-on desktop gadget that stands in for the PC’s HDD lamp and NIC activity lights, so you can watch load and transfer at a glance.
