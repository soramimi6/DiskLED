## 計画どおり入れたもの

### メーターの非対称バリスティック

アナログ／PPM 風。fps（10 / 15 / 20）を変えても時間あたりの動きが揃う。

- **上昇**（表示値 ＜ 実測）: 指数でグッと追いつく
- **下降**（表示値 ＞ 実測）: 定速スルーレートでスーッと落ち、目標で止まる（行き過ぎなし）
- LED と Ping 段階は従来どおり即時。数値（％）は 1 秒間隔のまま（表示用メーター値を参照）
- 起動約 0.9 秒のスケールアップ演出はバリスティックの対象外

時間定数:

- 上昇: `k = 1 - exp(-Dt / AttackTau)`。`AttackTau` はプロファイルの速い τ〜遅い τ を Strength（0–100）で補間。大きいほど上昇が速い
- 下降: `v = max(target, current - FallSpeed * Dt)`。`FallSpeed` はプロファイル定数（Strength では変えない）
- `Dt` は前回更新からの秒。上限約 0.25 秒（ポーズ明けの飛びを抑える）
- 差 0.01 未満は上昇／下降の向きを維持。上昇のみ差 0.004 でスナップ

### スキン設定 `[Ballistic]`

`assets/<id>/layout.cfg`。未指定は `vu` / `50`。

| キー | 意味 |
|------|------|
| Default | 既定プロファイル `vu` / `bar` / `peak` |
| Strength | 既定の上昇強度 0–100 |
| Cpu / Mem / Swap / DiskReadMeter / DiskWriteMeter / NetInMeter / NetOutMeter | `プロファイル` または `プロファイル,強度` |

プロファイル（見た目のキャラクター。メーター種名ではない）:

| キー | 想定 | 上昇（標準） | 下降 |
|------|------|----------------|------|
| `vu` | コマ数多めの針 | τ ≈ 0.08 秒 | フルスケール約 0.8 秒 |
| `bar` | 粗い LED バー | τ ≈ 0.11 秒 | フルスケール約 0.5 秒（余韻短め） |
| `peak` | スパイクを見せる活動計 | τ ≈ 0.04 秒 | フルスケール約 1.3 秒（余韻長め） |

同梱初期値:

- Original: Cpu / Mem / Swap = `vu,55`、速度 4 本 = `peak,80`
- Metalic: Cpu / Mem / Swap = `bar,50`
- Crystal: Cpu / Mem = `bar,50`

書式の詳細は `assets/LAYOUT.md`。

### 推移グラフは実測ベース（区間内ピーク）

フル表示の履歴は、バリスティック後の表示値ではなく **RangeEngine 正規化直後の実測（0..1）** を積む。更新間隔のあいだに来たフレームは捨てず、**系列ごとの最大** をホールドして 1 点にする。

### ホバー情報（ツールチップ）

本体ウィンドウにマウスを乗せると、短い遅延のあと Windows 標準ツールチップで次を表示する（旧 2.x のフローティングではない）。

```
DiskLED 3.0.1
 CPU: 12%
 MEM: 45%
 SWP: 3%
 Disk I/O: 12.3 MB/s
 Net I/O: 340 KB/s
 Ping: 30ms (mg6.jp)
```

- 版は exe の VERSIONINFO（末尾 `.0` は省略）
- ％はメーター数字と同じ 1 秒ホールド値。Crystal でも SWP を出す
- Disk I/O / Net I/O は Read+Write / In+Out の実測合算。単位は値に応じて B/s・KB/s・MB/s・GB/s（1024 進）
- Ping は直近 RTT と **実際に送った先**（ゲートウェイ自動ならその IP）。失敗は timeout、無効は off、計測中は …
- **表示の更新は全項目 1 回/秒**（組み立てた文言を 1 秒ホールド。トレイ Hint も同じ）
- トレイアイコンの Hint も同じ文言
- 全面 HTCAPTION のため VCL Hint は使わず、NC マウス＋ `TTF_TRACK` で出す。ドラッグ中は出さない

## 計画書には無く、3.0.1 で一緒に出したもの

公開 CHANGELOG にある追加分。

- 常駐負荷: 見た目のコマが変わったときだけ再描画（計測は表示 fps と同じ）
- Original: ネット LED を送受信別（In / Out）。アナログメーター 64 コマ。フル表示の推移グラフは棒
- Crystal: CPU / メモリ レベルバーを 32 コマに補間
- Metalic: フル表示の推移グラフは折れ線（従来どおり）
- ネット速度の反応を直線（既定）と対数で切替可能（オプション）。ディスクはオートセンスの直線のみ。切替時は推移グラフをクリア
- 終了時にもスタートアップ登録を現在の設定へ合わせる（移動後の exe パス付け直しを含む）

## リリース時の確認観点（出荷時に実施）

- Original の 64 コマ針: 上昇がキビキビ、下降が惰性
- Crystal の 32 コマバー: `bar` で滑らかに追従するか
- Disk / Net の短いスパイクが `peak` で立ち上がり、余韻が残るか
- オプションで fps を 10 と 20 に変えて、時間あたりの落ち方が大きく違わないか
- フルグラフがメーターの余韻ではなく実測の形になっているか。短いスパイクが針で見えたら、次のグラフ点にピークとして残るか
- マウスホバーで版・使用率・Disk/Net I/O・Ping 先が出ること。I/O 単位が速度で切り替わること。ドラッグ中は出ない。Crystal（高さ 14px）でもチップが読めること。Stay on top でも手前に出ること
