# DiskLED 3.1.0（実装メモ）

3.0.1 は **2026-08-30 公開済み**（`v3.0.1`）。3.1.0 のダッシュボードと PMv2 スケールは **実装済み**（作業ブランチ `feature/3.1.0`）。  
公開文の正本は `public_docs/`（JA+EN）。モジュール詳細は `docs/DESIGN.md` §16。

計画時点の「整数倍切り捨て（125%→1x）」「ダッシュボードに NIC 名一覧」は **採用していない**。

## 入れたもの

1. **高 DPI（Per-Monitor V2 維持）**
   - ガジェット: 0.5 刻み（1 / 1.5 / 2…）。**125% は見た目 1.5 倍**
   - ダッシュボード: 実 DPI（`Dpi/96`）。フォーム `Scaled=False`
   - オプション: VCL `Scaled=True`
2. **ダッシュボード**（常駐とは別ウィンドウ）
   - 左カラム: セクション＝ドーナツ | 履歴（5 分、1 Hz）。ドーナツは約 5 Hz
   - 右カラム: CPU / メモリ / 電源 / ディスクキュー / Ping（上からこの順）
   - OS アプリのライト／ダーク。終了時に開いていれば次回復元（位置・サイズは DIP）

## 入れなかった（3.1.0 でも対象外）

- フローティング、サウンド、複数起動、OwnerDraw メニュー
- マウス接近で隠す／最大化でトレイ退避
- 手動速度レンジ UI、手動言語切替
- 個別ドライブ／NIC を選んで表示を固定すること
- ダッシュボードへの NIC 名一覧（ペインタに `DrawNicList` はあるが未接続）
- GPU、ユーザー導入 `.dla`、SSTP
- ガジェットの連続倍率（1.25x）と DPI Unaware への戻し

## 確認済みの利用者向け挙動

- 100% / 125% / 150% / 200% でガジェット・ダッシュボード・オプション
- ドーナツは滑らか、中央の数字は 1 秒
- ライト／ダーク切替はダッシュボードのみ追従
