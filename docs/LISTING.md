## 一行紹介

CPU・メモリ・ディスク・ネットと Ping を、デスクトップ常駐メーターで眺める Windows 用ガジェット（DiskLED 3）。

## 短い紹介（120 字前後）

Windows 10/11 向けの常駐システムモニターです。CPU・メモリ・ディスクアクセス・ネットワーク・Ping をメーターと LED で表示します。旧 DiskLED を現代 OS 向けに再構築した無料ソフトです。

## 機能箇条書き（掲載フォーム向け）

- CPU / 物理メモリ / SWAP 使用率の表示
- ディスク読み書き LED と速度バー（全ディスク合算）
- ネットワーク送受信 LED と速度バー（オプションで直線／対数）
- Ping 応答の 4 段階表示（手動即時更新・オプションでオフ可）
- 表示モード 4 種（Original / Crystal / Metalic / Info Bar）
- Original / Metalic のフル表示では推移グラフ（Original は棒、Metalic は折れ線）
- ダッシュボード（別ウィンドウ。ドーナツと 5 分履歴、ライト／ダーク）
- 高 DPI（Per-Monitor V2。ガジェットは 0.5 刻み）
- 単一起動、最前面、トレイ、スタートアップ
- 管理者権限不要
- 英語 UI が既定（OS が日本語 UI のときだけ日本語）

## カテゴリ案

- システム／ハードディスク／モニタリング／デスクトップアクセサリ

## 旧版ページを更新する場合の一言

Windows XP 時代の DiskLED を、Windows 10/11 向けに基本設計から再構築したメジャーアップデート（3.x）です。旧スキン（`.dla`）は非対応です。同梱の表示モードをお使いください。正式配布はアンインストール対応のインストーラー（`DiskLED_Setup_3.1.0.exe`）です。上級者向けにポータブル zip も用意できます。

## プライバシー（掲載用）

本ソフトは広告を表示しません。定期的な外部送信は、ユーザーが有効にした Ping（ICMP。既定先 `mg6.jp`）と、起動時 1 回の GitHub Releases Latest（新しい版の確認。オプションでオフ）だけです。個人情報の収集・送信は行いません。
